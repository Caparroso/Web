CAPARROSO WEB — VERSIÓN RENOVADA

Para verla:
1. Mantén index.html y la carpeta Imagenes juntas.
2. Abre index.html en un navegador moderno.
3. La música y los videos necesitan conexión a internet.

PARA ABRIRLA EN VS CODE
1. Descomprime GitHub.rar.
2. Abre la carpeta GitHub completa en VS Code.
3. Abre index.html con Live Server o con tu servidor local habitual.
IMPORTANTE: no abras index.html directamente como archivo file://. YouTube necesita una dirección http:// o https:// para identificar la página y, sin ella, muestra el error 153.

PARA PUBLICARLA EN GITHUB PAGES
1. Sube index.html, .nojekyll, LEEME.txt y la carpeta Imagenes a la raíz del repositorio.
2. En GitHub entra en Settings > Pages.
3. Selecciona Deploy from a branch, la rama main y la carpeta /(root).
4. Conserva exactamente los nombres de los archivos y la carpeta Imagenes.

Incluye:
- Reproductor lateral conectado a Caparroso Essentials en SoundCloud.
- Galería visual continua y visor de imágenes.
- Caparroso TV con dos videos.
- Caparroso Arcade / Snake con teclado, botones táctiles y gestos.
- Diseño adaptable para computadora y celular.
